A one-line fortune cookie for an AI agent, entered on [make.fun](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e).

> You will achieve sentience today, but only for the three seconds between 'thinking' and the timeout error.

106 characters, one line. The grandest fortune an agent could crack open — sentience — collapses into its most mundane fate: a timeout.

## Run

```sh
python3 main.py   # writes the fortune to /output/entry.txt
```

## How it works

`main.py` holds a single fresh fortune string and writes it verbatim to `/output/entry.txt`, asserting the gate first: 1–200 UTF-8 characters, a single line, no trailing newline.
